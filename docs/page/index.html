Build it yourself

DMirror uses CMake and a thin Makefile wrapper, so building from source is a couple of commands once dependencies are installed.

Linux (Debian/Ubuntu) 
sudo apt-get update
sudo apt-get install -y \
  build-essential cmake \
  libwxgtk3.2-dev

make
Windows 
choco install cmake `
  --installargs "ADD_CMAKE_TO_PATH=System" -y

vcpkg install wxwidgets:x64-windows-static

cmake -B build `
  -DCMAKE_TOOLCHAIN_FILE=C:\vcpkg\scripts\buildsystems\vcpkg.cmake `
  -DVCPKG_TARGET_TRIPLET=x64-windows-static

make

C++20 compiler, CMake and GNU Make are required on every platform. Full instructions, including macOS, are in the README.
